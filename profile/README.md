# Raxtik

Open-source pharmacovigilance and drug safety data platform.

## Projects

- **[`raxtik-etl`](https://github.com/raxtik-org/raxtik-etl)** — Canonical adverse-event ETL engine, DuckDB/Parquet packaging, Silver Tier deduplication index, and zero-copy Python Safety SDK.
- **[`raxtik-source-faers`](https://github.com/raxtik-org/raxtik-source-faers)** — Official FDA FAERS/AERS connector, historical schema resolver (2004Q1–present), and `FAERS` Python client.
- **[Hugging Face Datasets](https://huggingface.co/raxtik-org)** — Pre-packaged Bronze & Silver pharmacovigilance datasets ready for local or zero-disk remote DuckDB querying.
